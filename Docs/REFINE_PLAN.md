# 機能改善計画

## 第2世代の敵車の色を第３,4世代のように色違いがあるようにしてほしい

パレット替えな実装で

## 第２世代の車はY値でソート（上ほど奥）

上が奥、下が手前として

## 車同士は衝突判定をつけてほしい

衝突した場合は速度が落ちる

## コンクリート壁やタイヤ壁にぶつかったら速度大幅減

衝突音も欲しい

## 第３、４世代

自車がもう少し大きく映るようにして欲しい

## タイトルデモ中の世代見せ

5秒操作がなかったら世代を自動的に切り換えて 1から4世代をループで見せルモードになってほしい
1世代は5秒ごとに切り換え

ゴールしてレースが終わったらリスタートして自動的にループさせる
